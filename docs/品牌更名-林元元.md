# 林元元品牌更名

本次统一替换小程序 A/C 端、管理后台 B 端、隐私提示、分享标题、支付商品说明、商品详情模板、项目显示名称、文字设计稿与文档中的品牌显示内容。字体、字号、间距、配色、组件结构、产品构图与动画保持原样。

旧商品、订单商品和 Banner 文案在展示时转换为新品牌，不会覆盖云数据库原始数据；后台保存商品时可将转换后的文案持久化。账号、密码、支付签名、推广码、AppID、云环境和文件路径保持原值。现有目录名称及内部包/技能标识保留，以免破坏工具和历史链接。

旧客服微信、合作邮箱已从页面撤下，暂显示“请通过小程序客服咨询”。确认实际新联系方式后，再填入关于页面；未自行生成新微信号或邮箱。

发布需同步更新小程序、admin-web 静态文件（含 brand.js）及 pay/init/updateProductDesc 云函数代码。本次未连接云环境、部署或修改微信公众平台/商户平台资料。已存在的云端图片、已发出的分享卡片和微信平台显示名称需在对应平台更新。

历史 UI 截图与已批准的渲染图仍作为历史参考保留。商品卡片只取参考图中的产品区域，不展示参考图顶端的旧品牌标题；未重新生成图片，以保持原有产品外观与构图。

验证：`npm run test:brand` 通过；smoke 208 项、模拟 E2E 150 项、页面加载、权限、佣金、扫码登录、退款诊断和云函数语法检查通过。

`npm run verify` 在退款一致性用例 `approvalOnlyQueuesAndRejectRaceDoesNotReverseCompletedRefund` 处失败（`approved` 与 `pending_auto` 不一致）。使用更名前的 HEAD 版 admin 云函数复测，同一用例也失败，本次未改动退款业务逻辑。
