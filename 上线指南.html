在微信开发者工具左侧文件树，找到 cloudfunctions 文件夹，对下面 每一个 子文件夹右键 →「上传并部署：云端安装依赖（不上传 node_modules）」：

⚠️ 全部 12 个都要上传！这次改了 6 个云函数的 envId，如果不重新上传，线上环境还是旧的 DYNAMIC_CURRENT_ENV，可能导致部分功能在正式版中报错。

每个上传成功后右下角会提示"上传成功"，等全部 12 个都传完再进行下一步。

2 编译测试 必须
  1. 点击开发者工具顶部的「编译」按钮（或 Ctrl+B / Cmd+B）
  2. 在模拟器中走一遍核心流程：浏览商品 → 加购 → 下单 → 支付
  3. 进入管理后台，确认筛选栏、退款处理、客服消息都正常
  4. 点击「预览」生成二维码，手机扫码在真机上再测一遍
✅ 确认所有功能正常后再进入下一步。如果发现问题，先修复再上传。
3 上传小程序代码 必须
  1. 点击开发者工具顶部的「上传」按钮
  2. 填写版本号：1.0.0（首次上线）
  3. 填写备注：首次上线
  4. 点击确定，等待上传完成
⚠️ 上传前确保「不校验合法域名」已关闭（详情 → 本地设置），否则审核可能被拒。
4 提交审核 & 发布 必须

打开浏览器，登录 mp.weixin.qq.com（微信公众平台）：

  1. 设置服务类目（如果还没设置）：
    管理 → 基本设置 → 服务类目 → 添加类目
    建议选择：电商平台 / 综合电商（需要有相关资质）
  2. 配置隐私协议（审核必须）：
    设置 → 用户隐私保护指引 → 新增/更新
    勾选：微信昵称、头像、手机号（如有）、地址
    填写收集目的（如"用于订单配送""用于客服沟通"）
  3. 提交审核：
    管理 → 版本管理 → 找到刚上传的 1.0.0 版本
    点击「提交审核」→ 填写审核信息 → 提交
  4. 发布上线：
    审核通过后（通常 1-3 天），回到版本管理
    点击「发布」→ 小程序正式上线！
⚠️ 审核常见被拒原因：服务类目与实际业务不符、缺少隐私协议、测试账号未提供。建议在提交审核时备注一个测试账号。
🔍 审核注意事项
  1. 测试账号：提交审核时填写一个可测试的账号（你的微信号），方便审核人员体验
  2. 支付功能：由于涉及微信支付，确保商户号已关联小程序 AppID，否则支付类目审核会卡住
  3. 客服功能：小程序后台 → 客服 → 添加客服人员（你的微信号），不然审核可能提示无客服入口
  4. 首页不能为空：确保云数据库中已初始化商品数据（init 云函数已跑过）
  5. 域名配置：如果商品图片用了外部 URL，需要在 mp.weixin.qq.com → 开发 → 开发设置 → 服务器域名中添加

审核通过后小程序就能正式使用了 🎉
