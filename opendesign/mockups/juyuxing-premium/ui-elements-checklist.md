# 林元元商城 UI 重设计 - 完整元素清单

> 基于项目当前的 24 个页面、11 个公共组件和完整交易/分销/管理流程梳理。
> 设计方向：现代高端洗化官方商城，以 Aesop / Le Labo 式天然实验室气质为参考，克制、专业、简约，不做可爱风。
> 当前核心视觉稿：`home.html`、`product.html`、`category.html`、`cart.html`、`user.html`。

---

## A. 全局框架

- 微信系统状态栏：时间、信号、电量，与页面背景自然衔接
- 顶部导航 TopBar：返回、页面标题、搜索、分享、更多，以及微信胶囊按钮避让区
- 底部 TabBar：仅 3 个主 Tab（首页 / 购物车 / 我的）；分类通过首页或搜索进入
- TabBar 状态：默认、激活、购物车数量角标/消息红点
- 安全区：底部 34rpx `safe-bottom` 留白(iPhone 底部指示条)
- 页面容器：标准左右边距、内容最大宽度、固定底栏占位、长页滚动区
- 装饰元素：草本线稿、配方编号、印章、细分隔线、英文 eyebrow，小面积使用

## B. 设计系统（沿用现有视觉稿）

- 主画布：暖米白 `#F5F1EB`；浅背景 `#FAF7F2`；柔和分区 `#EFE9DF`
- 表面：白 `#FFFFFF`；分割线 `#E8E2D8`；弱分割线 `#F0EBE2`
- 文字：主墨 `#1F1B16`；软墨 `#3A332B`；辅助 `#7A6F62`；弱文字 `#A89F92`
- 品牌色：松墨绿 `#2D4A3E`；鼠尾草绿 `#5C7868`；暖琥珀 `#B8845C`
- 交易强调：陶土红 `#C8553D`，只用于价格、主要购买 CTA、危险提示
- 语义：`#6B8E5A` 成功 / `#D89E4F` 警告 / `#C8553D` 危险 / `#5B7B9D` 信息
- 字体：Cormorant Garamond + Noto Serif SC（品牌/标题）；PingFang SC（正文）；SF Mono（订单号/物流号）
- 字重：正文 400，强调 500，避免大面积粗体
- 英文 eyebrow：全大写或小型大写，字距 `0.18em`，字号 18-22rpx
- 字号：xs 22 / sm 26 / md 30 / lg 34 / xl 40 / 2xl 48 / 3xl 56(rpx)
- 间距：8rpx 基础网格；页面边距 28-32rpx；区块间距至少 64rpx
- 圆角：卡片 12-20rpx；按钮 8-12rpx；只允许标签、头像、单选点使用 pill/圆形
- 边框：优先 1rpx 细线；阴影最大 `0 8px 24px rgba(42,38,34,.08)`
- 图片比例：商品主图 1:1；Banner 15:8 或 16:9；编辑内容图宽度统一
- 图标：统一线性图标，1.5-2rpx 描边；24/32/40rpx 三级尺寸
- 触控：可点击区域不小于 88×88rpx；禁用态保持可识别对比度

## C. 公共组件（11 个）

| 组件 | 模式 | 关键元素 |
|---|---|---|
| goods-card | grid / list | 封面图、角标(新品/热销/推荐)、品名、副标题、价格(`¥` + 主价 + 划线原价)、行内 + 按钮 |
| coupon-card | — | 左侧金额(`¥50` 或 `8折`)、使用门槛、有效期、右侧按钮(领取 / 已领取 / 已使用 / 已过期) |
| countdown | — | 天/时/分/秒，前缀/后缀文案，结束态 |
| spec-picker | 弹层 | 商品图+浮动价格、库存提示、已选、规格 chip(可选/禁用)、数量步进、底部双按钮 |
| price-tag | sm/md/lg + color 变体 | `¥` 符号 + 主值 + 划线原价 |
| status-tag | 7 种状态 | pending / paid / shipped / received / refunding / refunded / cancelled |
| empty-state | — | 图标、主文案、行动按钮(可选) |
| error-state | — | 图标、错误文案、重试按钮 |
| skeleton | card / list / banner / detail | 灰块占位 |
| region-picker | 弹层 | 三级 Tab(省/市/区) + 列表 + 取消/确定 |
| privacy-popup | 弹层 | 标题、正文(含隐私协议链接)、拒绝 / 同意按钮 |

此外需要建立以下基础组件：顶部导航、底部 TabBar、主/次/文字/危险按钮、搜索框、表单行、标签 chip、数字角标、分段控制、时间线、确认弹窗、Toast。

## H. 设计交付时必须覆盖的状态

每个页面不能只画一个“有数据”的静态画面，至少检查以下状态：

1. 默认有数据
2. 首次加载骨架
3. 空数据
4. 网络错误与重试
5. 下拉刷新/加载更多/已经到底
6. 未登录与已登录
7. 按钮禁用与提交中
8. 超长商品名、超长地址、超长订单号
9. 低库存、售罄、下架
10. iPhone 安全区和微信胶囊避让

## I. 推荐设计顺序

**P0：先完成可购买闭环**

首页 → 分类/搜索 → 商品详情/规格选择 → 购物车 → 确认订单 → 支付结果/订单详情 → 地址选择。

**P1：再完成复购与服务**

个人中心 → 订单列表 → 物流 → 退款售后 → 收藏 → 优惠券 → 客服 → 关于品牌。

**P2：最后完成增长与经营**

邀请有礼 → 代理申请 → 代理中心 → 提现 → 管理后台 → 商城编辑器。

## J. 高端简约风执行原则

按"高端低调 / Aesop 风"已确立的方向，每个新页面都应保持：

1. 留白大于装饰：区块之间至少 64rpx 呼吸，不用密集卡片堆叠。
2. 商品是主角：首屏必须看到真实产品、包装、质地或使用方式。
3. 标题使用中英衬线组合，正文用清晰无衬线；英文 eyebrow 保持统一字距。
4. 墨绿承担品牌与主操作；陶土红只承担价格、购买和危险语义；暖琥珀只点缀。
5. 卡片 12-20rpx、按钮 8-12rpx，避免大圆角、胶囊按钮和“可爱”图标语言。
6. 以细边框和材质色块建立层级，阴影只用于固定底栏、弹层和少量悬浮元素。
7. 一屏一个视觉重心，装饰只使用印章、编号、草本线稿、英文小标题中的少数几种。
8. 动效克制：页面入场、图片切换、抽屉上滑、收藏反馈即可，时长 180-320ms。

> 这份清单可直接作为 Figma 页面树、组件库清单和验收 checklist 使用。
